# FluxCore Cost Optimisation

FluxCore is an AI-assisted economic intelligence and cost optimization workspace for energy, trading, and operations decision support. The project combines a React-based frontend with a FastAPI backend to simulate planning, decisioning, and digital-twin style monitoring workflows.

## Features

- Interactive dashboard for operational insights and strategy views
- FastAPI backend for agent orchestration and API services
- Knowledge-driven decision support for energy and cost optimization
- Digital twin and monitoring components for operational visibility

## Project Structure

- `src/` – frontend React and Vite application
- `backend/` – FastAPI services, agents, and domain logic

## Getting Started

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
python main.py
```

## Notes

This repository is intended for local development and demonstration of an agent-driven cost optimization platform.
